# КРОВОСТОК — Переписки

Небольшая сюжетная игра в интерфейсе мессенджера. Главы «Четверг», «Пятница», «Выходные» и «Понедельник»; криминальный абсурд, независимые истории и решения, меняющие чужие сообщения.

**Играть:** `index.html` в браузере. Проект рассчитан на публикацию через GitHub Pages (`main`, папка `/`) и не использует сервер, сборщик или внешние библиотеки.

## Что реализовано

- 54 последовательные игровые сцены, **162 варианта ответа** (три на сцену).
- Переписки с Серёгой, Валериком, Шуриком, Томазиком, Аллой, Доком, Маратом, безымянным убийцей, Старым, Барменом, Восемь, Коляном и Сонным.
- Ветвления: выбор из предыдущих чатов меняет дальнейшие сообщения; история Коромысла не объявляется доказанной причиной находки у Серёги.
- Сообщения появляются по одному; перед входящими показывается «печатает…».
- Звук уведомлений синтезируется через Web Audio (без внешних файлов). Из-за правил браузеров звук запускается **после первого действия пользователя**.
- Список контактов, непрочитанные сообщения, штампы времени, отметки доставки, медиа-вложение, поиск по контактам.
- Сохранение истории и решений в `localStorage`; восстановление после перезагрузки страницы.
- Кнопка показа оставшихся сообщений без ожидания, скорость 1× / 2× / ∞, выключение звука, сброс прохождения.
- Интерфейс для телефона и десктопа; с телефона можно возвращаться к списку переписок.
- **Никакого вступительного экрана**: при открытии сразу начинается разговор.

## Структура

```
index.html           — интерфейс
styles.css           — оформление и адаптивность
app.js               — движок диалогов, уведомления, локальный прогресс
story.js             — данные сцен и последствий (работает и через file://)
assets/              — иконка и стилизованное вложение
SCENARIO_NOTES.md    — редакторские заметки
```

Для редактирования сюжета меняйте `story.js` (объект `window.KROVO_STORY`). Скрипт `make_story.py` совместно с `weekend_story.py` и `monday_story.py` используется при пересборке этого файла на основе первого игрового сценария и добавленных сцен; это редакторский инструмент, для запуска игры не требуется.

## Проверки

В `tests/test_smoke.py` — проверка двух полных прохождений по всем 54 сценам и мобильного интерфейса с Playwright/Chromium. `tests/test_weekend.py` проверяет межчатовые последствия, пересылку в новый сюжет и миграцию старого завершённого сохранения. `tests/test_monday.py` проверяет четыре исхода новой главы, настоящую доставку пересылок и совместимость завершённого сохранения v0.5. Тесты не нужны игроку.

## Сценарная позиция

Игрок не носит имя Тимур по умолчанию. Он получает сообщения от знакомых и неизвестных; может отвечать и пересылать сведения, но не обязан быть профессиональным посредником. Истории «Голова», «Коромысло», «Шурик», «Летом» и другие используются как основа новых игровых диалогов, а не как перепечатанные тексты песен. Сюжетные связи, отсутствующие в исходных песнях, являются авторскими игровыми допущениями. Это **прототип четырёх игровых глав**, не законченный полный сценарий всей вселенной.

## Изменения v0.6.0 — «Понедельник»
