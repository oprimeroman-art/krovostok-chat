# КРОВОСТОК — Переписки

Сюжетная веб-игра в интерфейсе мессенджера. Оригинальные игровые диалоги по мотивам историй группы «Кровосток», **не архив текстов песен**.

**Играть:** https://oprimeroman-art.github.io/krovostok-chat/

## Сборка 0.6 — «Понедельник»

- 54 сцены, 162 игровых ответа, 13 контактов.
- Четверг, пятница, выходные, понедельник. Новые линии: «Ногти» (контакт «Восемь») и «Приснился» (Колян, Сонный и Вача).
- Решения в одном чате меняют содержание и исходы в других: кто узнаёт про угрозу, кому пересылают сообщение, кто верит слуху и кто его опровергает.
- Сцены показываются в мессенджере постепенно с индикатором «печатает…», звуками, временем, доставкой и непрочитанными.
- **Нет автопереключения чатов** и нижних игровых баннеров.
- Сохранения старых версий продолжаются без потери истории: после F12 начинается S01, после S14 — M01.
- Фотография головы от автора встроена в assets/head-kitchen.jpg, открывается крупно из переписки.
- Без сервера и внешних библиотек, только статический HTML/CSS/JavaScript.

## Структура

- `index.html` — страница, загружает `styles.css`, `story.js`, `app.js`.
- `app.js` — движок, чаты, уведомления, сохранения.
- `story.js` — опубликованный сценарий.
- `data/thursday_base.json`, `weekend_story.py`, `make_story.py` — исходная редакторская база до версии 0.5.
- `data/monday_scenes.json` — 16 новых сцен в редактируемом JSON.
- `make_story_v06.py` — воспроизводимо собирает всю историю (предыдущий генератор, затем понедельник).
- `SCENARIO_NOTES.md` — отдельные правила канона и игровые допущения.
- `tests/` — браузерные тесты предыдущих версий.

### Пересборка

```bash
python make_story_v06.py
python build_single_file.py
```

`index.html` можно открывать локально или через GitHub Pages. `build_single_file.py` дополнительно создаёт автономный единый HTML-файл.

Важное различие: песни и их события — **источники мотивов**, а пересечения, новые имена, диалоги и альтернативные исходы придуманы для игры. Не выдаём сюжет адаптации за канон группы.
