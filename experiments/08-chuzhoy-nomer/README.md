# КРОВОСТОК — ЧУЖОЙ НОМЕР / эксперимент 08

Пересборка существующей чат-новеллы в однокомнатный интерфейс игры. Используются исходные данные `thursday_base.json` (12 сцен) и `monday_scenes.json` (16 сцен) из основного проекта, без переписывания их диалогов и решений. Сохранены персонажи, флаги и три авторских варианта ответа каждой сцены.

Игровые действия поверх исходного сценария:
- сохранять конкретные сообщения в личные записи;
- задавать отправителю уточняющий вопрос о происхождении сведений;
- пересылать конкретное сообщение выбранному контакту, наблюдать немедленную реакцию и рост/снижение районного шума;
- возвращаться к архиву переписок каждого контакта и собранным записям;
- выборы сцен сохраняются в наборе сюжетных флагов и влияют на итоги главы.

Один экран: активная переписка, контекстные действия внутри пузыря сообщения, компактная нижняя навигация. Нет отдельной левой/правой панели, таймеров и гонки на реакцию. Внешние библиотеки не используются.

Исходные файлы основного проекта и эксперименты 01–07 не изменены. Это отдельная сборка для проверки нового игрового цикла.
