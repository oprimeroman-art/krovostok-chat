# Лаборатория игровых экспериментов

Все прототипы в этой папке изолированы от основной игры «КРОВОСТОК — Переписки».

Основной проект и его опубликованная версия не меняются. Эксперименты можно свободно перерабатывать, удалять и менять по результатам тестирования.

## Эксперимент 01 — КОНТОРА: Районная смена

[Открыть демо](./01-kontora/)

Короткая управленческая стратегия на пять игровых дней. Игрок распределяет действия между заказами, разведкой, отдыхом, снижением шума и азартной игрой. Нужно собрать сумму на аренду, удержать доверие и не привлечь слишком много внимания.

Статус: первый играбельный прототип, v0.1.
