# КРОВОСТОК — Номера (эксперимент 03)

**Не новая история и не другой жанр.** Это альтернативный способ играть в существующие 144 сцены «Кровосток — Переписки». Не изменяет корневую версию и её сохранения.

## Что работает

- Те же сюжетные модули, персонажи, флаги, развилки, межчатовые пересылки и вложение с фотографией.
- Один большой экран разговора вместо постоянного двухколоночного мессенджера.
- Контакты открываются отдельной шторкой кнопкой «Все номера» (или клавишей C, если фокус вне поля ввода).
- Настоящая строка набора ответа. При фокусе появляются три сюжетно допустимых варианта. Набранное помогает найти подходящую формулировку; **свободный текст не интерпретируется как новый сюжетный выбор**. Точная ветка всегда видна в меню выбора.
- Клавиши 1/2/3 в режиме ожидания ответа; стрелки в поле ввода выделяют вариант; Enter отправляет выбранную сюжетную реплику. Нажатие на вариант тоже отправляет именно его.
- Личные заметки по любому собеседнику и история собственных ответов в этом чате. Контакты можно закрепить, чтобы они поднимались в списке.
- Сохранения и заметки хранятся в отдельных ключах localStorage, поэтому основной сайт не затронут.

## Проверка

Синтаксис `app.js` проверен через `node --check`; структурно проверены все DOM-id, используемые движком. Полное прохождение всех 144 сцен в браузере не проводилось.

## Реальные ограничения

Это изменение интерфейса, а не полная переделка сюжетной структуры: по-прежнему три авторских ответа на сцену и сохранён прежний сценарный порядок. Личные заметки — инструмент игрока, не новые сюжетные флаги.
