# КРОВОСТОК — КАДР / эксперимент 09

Отдельный визуально-игровой эксперимент. Не изменяет основную игру, эксперимент 04 или другие ветки.

## Что внутри
- Постановочная композиция: крупный персонаж и место действия слева, типографическая реплика и выбор справа.
- Оригинальный диалог E01 из `story.js` основной игры (90-сценная версия в текущем корневом файле).
- Три рабочих выбора с различными последствиями и отметками состояния.
- Переключение голосов Серёга / Валерик / Шурик / Марат.
- Отдельная карта связей с визуальным различием известных контактов и предположений.
- Адаптивная вёрстка, клавиши 1/2/3, Escape для закрытия карты.

## Запуск
Открыть `index.html` через GitHub Pages:
`/experiments/09-kadry/`

## Честные ограничения прототипа
Это первый вертикальный срез, а не перенос всех 90 сцен. Диалог Серёги E01 взят из корневого `story.js`. Реплики других контактов взяты из соответствующих сцен E03/E04/E08; они показаны как переключаемые голоса, а не как уже разблокированные сюжетные ветки. Выборы E01 имеют локальные последствия в этом прототипе; они пока не подключены к полному графу флагов основной игры. Следующий этап — адаптировать весь сценарный граф, не теряя исходные условия и развилки.
