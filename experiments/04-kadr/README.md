# ШИЛО — Чужая история

## Только первый этап: согласование оформления

[Открыть игровой фрагмент](https://oprimeroman-art.github.io/krovostok-chat/experiments/04-kadr/).

Полная разработка остановлена до прямого одобрения пользователя. Этот фрагмент не является полной игрой.

### Что работает

- Главный экран, новая игра и продолжение фрагмента.
- Пять собеседников с индивидуальными полноразмерными иллюстрациями и окружением.
- Шесть разговоров: E01 и E02 Серёги, E03 Шурика, E04 Валерика, E08 Марата и реплики Дока из условного ответвления E04.
- Оригинальные ответы и связанные с ними реплики; флаги E01 влияют на E02. Решение о пересылке снимка влияет на разговор Валерика, если он открыт после решения.
- Свободный выбор контакта, независимое место в каждом разговоре, пауза ожидания при переключении.
- Последовательное появление реплик, пропуск ожидания, перечитывание разговора.
- Отдельное локальное сохранение `shilo-art-prototype-v1`, звуковой сигнал по желанию.
- Десктопная и мобильная композиции, клавиши 1–3, пробел и Escape.

### Границы фрагмента

Для художественного просмотра все пять контактов доступны сразу. Это выбор отдельных ситуаций из сценария, а не хронологическое прохождение полной истории. Разговор Дока выделен для просмотра портрета и интерьера, поэтому доступен и без пересылки снимка. Последствия за пределами выбранных разговоров пока не реализованы. Снимок не открывается как отдельное вложение; его исходная текстовая ремарка заменена в демонстрации нейтральным описанием иллюстрации.

`demo-story.js` содержит выборку из исходного `story.js`; исходные сценарные модули и `engine.js` сохранены без изменений. Старая оболочка (`stage.js`, `stage.css`, `portraits.webp`) также сохранена, но не загружается новой страницей.

### Изображения

`art/serega.webp` — предоставленный пользователем концепт с кухней. Остальные полноразмерные иллюстрации созданы для прототипа встроенной генерацией изображений: Валерик у гаражей, Шурик на Филиппинах, Марат на лестнице, Док в ординаторской и двор для главного меню. `*-small.webp` используются только в списке контактов; большие иллюстрации из них не растягиваются. Шрифт Open Sans Condensed Bold включён локально; лицензия Apache 2.0 находится в `art/FONT-LICENSE.txt`.
