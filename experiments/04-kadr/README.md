# ШИЛО — Чужая история

Криминальный графический роман по мотивам песен «Кровостока». 18+.

[Открыть игру](https://oprimeroman-art.github.io/krovostok-chat/experiments/04-kadr/)

Одиннадцать дней самостоятельных историй, встречи и решения с последствиями. Утверждённые иллюстрированный экран, контакты, типографика и музыка сохранены. Новые персонажи появляются по ходу событий. Записи и прогресс сохраняются в браузере; настройки музыки и эффектов независимы.

Выбор — мышь или 1–4. Пробел — ожидание в законченном разговоре. Переход к другому человеку не тратит время. Завершив разговоры дня, можно убрать телефон до утра. Главное меню позволяет продолжить, начать заново или настроить звук.

- CAMPAIGN.md — устройство полной истории и авторские развязки.
- SONG_SOURCES.md — прочитанные тексты и опорные обстоятельства.
- WORK_ORDER.md — актуальное поручение.

Полная сборка предназначена для совместного прохождения. Новые проверки отложены по указанию пользователя. Исходные сценарии и остальные эксперименты сохранены.
