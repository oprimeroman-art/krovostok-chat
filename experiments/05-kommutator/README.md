# КОММУТАТОР — эксперимент 05

Самостоятельная браузерная игра. Оригинальные проекты и эксперимент 04 не затрагиваются.

Игровой цикл: принять вызов → выслушать две части разговора → вручную соединить входящую линию с одним из контактов → получить реакцию → увидеть накопившиеся последствия к концу смены. Пять вызовов, три варианта маршрутизации на каждом, четыре разных финальных состояния.

Управление: нажать на трубку или Space; нажать «Подслушать линию» или L; выбрать гнездо на панели либо клавиши 1–5.
