# ПЕРИГЕЙ — буксирный рейс

Самостоятельная аркадная игра с физикой инерции и тросовым перемещением. Не использует сетевые библиотеки и внешние изображения.

## Игровой цикл
1. Выйти из шлюза и найти пять энергетических ядер в поле обломков.
2. Управлять кораблём с инерцией: тяга разгоняет, поворот меняет направление носа, тормоз гасит скорость.
3. Навести мышь на светящийся якорь и нажать кнопку мыши — гарпун цепляет трос. Натянутый трос ограничивает радиус и позволяет менять траекторию маятниковым движением.
4. Не разбить корпус об астероиды, не сжечь топливо.
5. После сбора всех ядер вернуться к маяку.

## Управление
- W / ↑ — тяга
- A / D или ← / → — поворот
- Мышь — зацепиться за ближайший якорь в направлении курсора; повторное нажатие или Q — отпустить трос
- Пробел — импульсное торможение
- R — перезапуск после провала или победы

## Особенность
Трос — не кнопка телепортации: корабль сохраняет инерцию, и натяжение меняет его движение. Можно разогнаться маятником, сорваться с якоря и пролететь через поле на сохранённой скорости.
